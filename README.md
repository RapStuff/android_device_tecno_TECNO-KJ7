Device configuration for TECNO Spark 20 Pro+
==============================================

The TECNO Spark 20 Pro+ (codenamed _"KJ7"_) is a mid-range smartphone from TECNO.

It was announced in December 2023 and released in February 2024.

## Device specifications

Basic   | Spec Sheet
-------:|:-------------------------
CPU     | Dual-core 2.2 GHz Cortex-A76 & Hexa-core 2.0 GHz Cortex-A55
Chipset | MediaTek Helio G99 Ultimate (MT6789)
GPU     | Mali-G57 MC2
Memory  | 8 GB RAM
Shipped Android Version | 14.0
Storage | 256 GB (UFS)
Battery | Non-removable Li-Po 5000 mAh
Display | 1080 x 2436 pixels, 6.78 inches (~393 ppi density), 120Hz AMOLED
Camera  | 108 MP wide camera, 2 MP macro camera, auxiliary lens, Quad-LED flash / 32 MP front camera
